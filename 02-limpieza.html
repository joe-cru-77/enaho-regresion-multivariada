Diagnóstico de faltantes, tratamiento de pases y recodificación de las variables

Esta etapa construye base_modelo: los asalariados ocupados con todas las variables del modelo completas y recodificadas. Es la misma lógica que se aplicó en PostgreSQL, escrita con dplyr para que se pueda reproducir sin una base de datos.

if (interim_listo) {

      "| asalariados ocupados:", fmt(nrow(asalariados)), "\n")

  cat("No está la base unida (datos/interim): se usa base_modelo.csv.gz ya generado o descargado de Zenodo.\n")

2.1 Diagnóstico de faltantes

Se distinguen dos tipos de celdas vacías:

  • Pase: la encuesta no le hace esa pregunta a esa persona. No es un error y no se elimina.
  • Faltante real: la persona debía responder y no hay dato, o tiene un código de «sin dato» (9, 99, 9999).
Código 
if (interim_listo) {
  faltantes <- asalariados %>%
    summarise(
      `Contrato (p511a)`          = sum(is.na(p511a)),
      `Sector (p510)`             = sum(is.na(p510)),
      `Tamaño de empresa (p512a)` = sum(is.na(p512a) | p512a %in% 9),
      `Ingreso (i524a1)`          = sum(is.na(i524a1) | i524a1 <= 0),
      `Lengua materna (p300a)`    = sum(is.na(p300a) | p300a %in% c(9, 99)),
      `Educación (p301a)`         = sum(is.na(p301a) | p301a %in% c(12, 99)),
      `Horas (p513t)`             = sum(is.na(p513t))) %>%
    pivot_longer(everything(), names_to = "Variable", values_to = "Faltantes") %>%
    mutate(`% de asalariados` = round(100 * Faltantes / nrow(asalariados), 2)) %>%
    arrange(desc(Faltantes))
  guardar_tabla(faltantes, "faltantes_modelo")
}
